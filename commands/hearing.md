# Hearing 起動

Hearing ステップのエントリポイント。質問票ではなく、**理解の提示と差分**で進める。

## 実行手順

### 1. トピック

ユーザーのメッセージにあればそれを採用。なければ地の文で「何について話しますか？」と聞く。

### 2. 理解の提示

トピックについて自分の理解を短く書く: 何を作るのか / なぜか / やらないこと / 置いた仮定 / 迷っている点。コードや creo-memories を読んで埋められることは先に埋める。

### 3. ズレと分岐

理解がズレていそうな所と、ユーザーが選ぶべき分岐だけを聞く。分岐が 2〜4 個に離散的に絞れているなら `AskUserQuestion`、開いた問いは地の文。「わからない」「後で決める」は仮定を置いて進み、仮定を書き残す。

### 4. 書き戻し

合意した理解を起票 memory の「AI の理解」節に書く（memory が無ければ起票する）。ユーザーの裁定は原文のまま引用する。
