# Spark

ひらめきを、意味付けされる前の生の状態で creo-memories に置く。**速さと原文が全て。**

## 実行手順

### 1. 言葉を受け取る

`$ARGUMENTS` があればそれが火花。無ければ地の文で一行だけ「何が降ってきた？」と聞き、次の発言をそのまま火花とする。

### 2. そのまま pack する

`mcp__creo-memories__remember` を一回呼ぶ。

- `category`: `spark`
- `content`: ユーザーの言葉を**原文のまま**。先頭に `# [SPARK] ` を付け、本文は `> ` で引用する。それ以外は書かない
- `atlasId`: session-start が出した Atlas 候補に exact match があればそれ。無ければ省略（Personal に入る）し、報告で一言添える。置き場で止まらない
- `supersedes`: `[]`（重複検出を切る。火花は重なってよい）
- `tags`: `["spark"]` と、プロジェクト名が分かればそれ

### 3. 一行で報告する

memory ID を一行返す。それで終わり。

## やらないこと

- 要約しない、見出しを付け直さない、タグを推測で増やさない、「AI の理解」を書かない。整えると火花が死ぬ
- 成功基準・非対象・Branch slug を聞かない。それは GO のときに todo へ進めるときの話
- 作業に入らない。pack した後は Conception の構え — 話したければ話す、話さなければそこで終わる
- 自分の連想があれば、memory に混ぜず会話で言う（「それ、さっきの X と繋がってる」）
